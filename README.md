# Telegram 量化助手机器人 + 菜单编辑工具

《起因是我写完全自动量化交易系统后想在Telegram上自动宣发自己的产品顺便写机器人菜单工具（量化助手.名/这里只是拿来打举例，你们可以自定义修改）灵感来源YouTube上的老艺术家博主;YuFeng Deng 峰哥》

一个让你的 Telegram 机器人有"菜单按钮"的小工具，自带一个**网页版可视化菜单编辑器**——不用懂编程，在网页上点点鼠标就能改机器人菜单。**如嫌麻烦或小白不会安装，可微信；DDDYYY100861 有收少数服务费**

## 这个项目是干嘛的（大白话）

- **机器人**：你在Telegram里创建了机器人（比如"量化助手"），它平时帮你接待消息、显示菜单按钮、按按钮回复内容。
- **菜单编辑器**：一个只在你本地电脑上运行的网页工具，用来改机器人的菜单（欢迎语、按钮布局、每个按钮回复什么话）。改完点"保存"，手机端发 /start 就能看到新菜单。

## 文件说明

| 文件 | 作用 |
|---|---|
| 启动量化助手.bat | 双击它，机器人开始上班（收发消息） |
| 启动菜单编辑器.bat | 双击它，打开菜单编辑网页 |

| menu_editor.html | 菜单编辑器的网页界面（一般不用碰） |
| .env | 钥匙盒：存机器人 Token（**不要外传，不要提交到 git**） |

## 第一次安装（其实做很简单）

**第 1 步：准备一个机器人 Token**
1. 在Telegram上注册一个机器人并取好起名字（比如"量化助手"）
2. 完成后 BotFather 会给你一串 Token（格式像 123456789:AAxxxxxxxxxxxx），复制保存好

**第 2 步：安装 Python**
1. 到官网 https://www.python.org/downloads/ 下载安装（装 3.10 或更高版本）
2. 安装时记得勾选 "Add Python to PATH"

**第 3 步：安装依赖库**
1. 打开项目文件夹，在文件夹地址栏输入 cmd 回车
2. 在黑窗口里输入下面命令回车：
   pip install python-telegram-bot

**第 4 步：放好 Token**
1. 在项目文件夹里新建一个文件，名字叫 .env
2. 里面写一行：
   BOT_TOKEN=你的Token

**第 5 步：启动机器人**
双击 启动量化助手.bat，黑窗口显示"量化助手已启动"就是成功了。

**第 6 步：测试**
手机 Telegram 找到你的机器人，发送 /start，应该会看到欢迎语和菜单按钮。

## 每天怎么用

1. 双击 启动量化助手.bat（机器人上班，黑窗保持打开）
2. 想改菜单：双击 启动菜单编辑器.bat，浏览器自动打开编辑网页
3. 在网页上改欢迎语、加按钮、改回复话术，点"保存菜单并生效"
4. 手机在机器人对话框里发 /start，新菜单就更新了
5. 不用时把两个黑窗口关掉（= 机器人下班）

## 常见问题

**Q：保存菜单后手机没变化？**
A：Telegram 的按钮是"发一次收一张"的卡片，改完菜谱后要在机器人对话框里**重新发 /start**，它才会把新菜单发给你。

**Q：两个黑窗是什么？**
A：启动量化助手 是机器人，启动菜单编辑器 是编辑器，两个都要开着才能"一边跑机器人一边改菜单"。别同时开两个同一个程序（会端口打架）。

**Q：端口 1001 / 1002 是什么？**
A：1002 是菜单编辑器在你电脑上的"门牌号"；1001 是给机器人留的标识。都是本地端口，不影响其它软件。
